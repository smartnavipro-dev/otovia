# Play Console — Data Safety セクション 回答書

## データの収集と共有

### Q: このアプリはデータを収集しますか？
**Yes**（ただし個人識別情報は収集しない）

収集するデータ:
| データ種別 | 内容 | 保存場所 | 暗号化 |
|-----------|------|---------|--------|
| OCR補正パターン | 誤認識文字列→正解文字列のペア | 端末内のみ | Yes（AES256-GCM） |
| アプリ設定 | 読み上げ速度、自動ページ送りのオン/オフ等 | 端末内のみ | No |
| APIクォータカウント | 外部API利用回数 | 端末内のみ | No |

### Q: データを第三者と共有しますか？
**Yes**

| 共有先 | 共有データ | 目的 | ユーザー制御 |
|--------|-----------|------|------------|
| Google（Gemini API） | OCRで読み取った書籍テキストの一部 | OCR誤字補正 | 制御不可（機能に必須） |
| 開発者 Google Spreadsheet | 補正パターン（from/toペアのみ） | アプリ改善 | 任意（「貢献する」ボタン押下時のみ） |

## 各設問への回答（Play Console フォーム）

### データの種類

**収集するデータカテゴリ:**
- [ ] 位置情報 → **No**
- [ ] 個人情報（名前・メール等） → **No**
- [ ] 財務情報 → **No**
- [ ] 健康・フィットネス → **No**
- [ ] メッセージ → **No**
- [x] ファイルとドキュメント → **Yes**（画面キャプチャ、ただし端末外送信なし）
- [ ] カメラ → **No**
- [ ] マイク → **No**
- [ ] 連絡先 → **No**
- [ ] カレンダー → **No**
- [x] アプリのアクティビティ → **Yes**（APIクォータカウント、端末内のみ）
- [ ] ウェブの閲覧履歴 → **No**
- [ ] アプリ情報とパフォーマンス → **No**
- [x] デバイスまたはその他の識別子 → **No**

### データの共有

**第三者との共有:**
- Google Gemini API: テキストデータ（OCRで読み取ったテキスト）
  - 目的: アプリ機能（OCR補正）
  - 任意か必須か: 必須
  - 暗号化: Yes（HTTPS）

- 開発者 Google Spreadsheet: 補正パターン（from/toペア）
  - 目的: アプリ改善
  - 任意か必須か: **任意**（ユーザーが明示的に「貢献する」を押した場合のみ）
  - 暗号化: Yes（HTTPS）

### セキュリティの実践

- データは転送中に暗号化されますか？ → **Yes**（HTTPS/TLS）
- ユーザーはデータの削除をリクエストできますか？ → **Yes**（設定画面から削除可能）
