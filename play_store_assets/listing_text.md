## 長い説明（4000文字以内）
```
Otoviaは電子書籍リーダーの画面をOCRで読み取り、AI（Gemini）でテキストを自動補正して音声読み上げするAndroidアプリです。通勤・家事・散歩中でも本を「聴く」体験を実現します。

■ 主な機能

【OCR+AI補正読み上げ】
画面に表示されている電子書籍のテキストをリアルタイムでキャプチャし、Google Gemini AIが誤字・記号混入・文字化けを自動修正してから音声で読み上げます。OCR特有の認識ミスを賢く補正するため、自然な日本語で聴けます。

【自動学習機能】
よく出る補正パターンを自動的に記憶・昇格させます。同じ本を読み続けるほど補正精度が上がり、APIコールを節約できます。ユーザーが手動で修正した内容も学習します。

【バックグラウンドプリフェッチ】
現在のページを読み上げている間に、次のページをバックグラウンドでOCR+AI処理しておく先読み機能。ページ切り替え時の待機時間をほぼゼロにします。

【自動ページ送り】
読み上げが終わると自動でページをめくります。アクセシビリティサービスを使ったスワイプジェスチャーで、どの電子書籍アプリにも対応（設定に応じて）。

【APIクォータ管理】
Gemini APIの1日の利用回数を管理し、無料枠内で効率よく使えます。残量が少なくなると通知します。

【パターン管理UI】
学習済みの補正パターンを一覧表示・削除できます。ユーザー手動パターンとAI学習パターンを区別して管理。

■ 使い方

1. アプリを起動して権限を許可（画面キャプチャ・アクセシビリティ）
2. 電子書籍アプリで読みたい本を開く
3. Otoviaのオーバーレイボタンをタップして読み上げ開始
4. 自動でページをめくりながら読み上げが続きます

■ 必要な権限

・画面キャプチャ（MediaProjection）：電子書籍画面のOCR処理
・アクセシビリティサービス：自動ページめくりのスワイプ操作
・インターネット：Gemini APIによるテキスト補正
・オーバーレイ表示（SYSTEM_ALERT_WINDOW）：操作UIの表示

すべての処理は端末内で完結します。個人情報の収集は一切行いません。

■ ご注意

・本アプリはGoogle Gemini APIを使用しています（無料枠あり）
・電子書籍の画面をOCRで読み取る仕組みのため、DRMや著作権の範囲内でご利用ください
・AIによる補正は完全ではありません。重要な内容は原文を確認してください

音で本の旅を。Otovia（音+via=音の道）で、読書体験を耳へ。
```

## アプリのアクセス権（審査コメント用）

```
このアプリは電子書籍の音声読み上げ支援を目的としています。

【SYSTEM_ALERT_WINDOW（オーバーレイ表示）】
読み上げ操作用のフローティングUIを画面上に表示するために使用しています。
ユーザーが任意のタイミングで読み上げを開始/停止/スキップできるインターフェースです。

【MediaProjection（画面キャプチャ）】
電子書籍アプリの画面をOCR処理するために使用しています。
取得した画像はOCR処理後に即座に破棄し、保存・送信は行いません。
ユーザーが明示的に許可した場合にのみ動作します。

【アクセシビリティサービス】
読み上げ完了後の自動ページめくり（スワイプジェスチャー）のために使用しています。
他のアプリのデータ読み取りや入力内容の収集は行いません。

視覚的な読書が困難な方や、ながら読みをしたい方のアクセシビリティ向上を目的としています。
テスト用アカウント: 不要（ログイン機能なし）
```
