## 🚨 **Issues Fixed**

### **1. Bitmap Memory Leak in shouldPerformOCR() [CRITICAL]**

**Location**: `OverlayService.kt:628-633`

**Problem**:
- When `shouldPerformOCR()` returned `false`, the bitmap was not recycled
- Occurred every time OCR was skipped (same page or waiting period)
- Memory leak: ~8MB per skipped OCR (1080p screen)

**Impact**:
- Memory leak of 80MB after 10 skipped OCR operations
- App crashes after extended reading sessions
- Affects all users, especially on low-RAM devices

**Fix Applied**:
```kotlin
if (!shouldPerformOCR(bitmap)) {
    debugLog("[v1.1.7] Bitmap recycled", "OCR skipped, bitmap released")
    bitmap.recycle()  // ✅ FIX: Release bitmap when OCR is skipped
    isCapturing = false
    return
}
```

### **2. Bitmap Memory Leak in processOCRImage() [CRITICAL]**

**Location**: `OverlayService.kt:1348-1363`

**Problem**:
- Original bitmap was not released after `bitmap.copy()`
- Occurred on every successful and failed OCR operation
- Memory leak: ~8MB per OCR execution

**Impact**:
- Memory leak of 800MB after reading 100 pages
- Guaranteed crash on low-spec devices
- Accumulates over time regardless of OCR success/failure

**Fix Applied**:
```kotlin
// Success case:
previousBitmap?.recycle()
previousBitmap = bitmap.copy(bitmap.config, false)
bitmap.recycle()  // ✅ FIX: Release original bitmap after copy
debugLog("[v1.1.7] Bitmap recycled", "Original bitmap released after OCR success")

// Failure case:
bitmap.recycle()  // ✅ FIX: Release bitmap on OCR failure
debugLog("[v1.1.7] Bitmap recycled", "Bitmap released after OCR failure")
```

### **4. Memory Usage Monitoring**

**Location**: `OverlayService.kt:569-593, 632-634`

```kotlin
private fun logMemoryUsage(context: String = "") {
    try {
        val runtime = Runtime.getRuntime()
        val usedMemory = (runtime.totalMemory() - runtime.freeMemory()) / 1024 / 1024
        val maxMemory = runtime.maxMemory() / 1024 / 1024
        val usagePercent = (usedMemory.toFloat() / maxMemory.toFloat() * 100).toInt()

        debugLog("[v1.1.7] Memory", """
            ${if (context.isNotEmpty()) "[$context] " else ""}
            Used: ${usedMemory}MB / Max: ${maxMemory}MB (${usagePercent}%)
        """.trimIndent())

        if (usagePercent >= 80) {
            Log.w(TAG, "[v1.1.7] ⚠️ High memory usage: ${usagePercent}% - Consider stopping reading")
        }
    } catch (e: Exception) {
        Log.e(TAG, "[v1.1.7] Failed to log memory usage", e)
    }
}
```

**Monitoring Schedule**:
- Every 10th page (page % 10 == 0)
- Logs memory usage at OCR start
- Warns when usage exceeds 80%

**Benefits**:
- Early detection of memory issues
- Helps identify leak sources
- Provides user warnings before crashes
