Otovia プライバシーポリシー

最終更新日：2026年2月24日

Otovia はユーザーの個人情報（氏名・メールアドレス・位置情報等）を一切収集しません。アカウント登録も不要です。

1. 収集する情報

端末内にのみ保存する情報

  • OCR補正パターン：「認識された文字」→「正しい文字」のペアのみ。書籍の内容・文脈は保存しません。
  • 利用設定：読み上げ速度・自動ページ送りのオン/オフ等のアプリ設定。
  • APIクォータカウント：外部API利用回数の管理（端末内のみ）。

これらのデータは端末内のアプリデータ領域に保存され、自動的に外部へ送信されることはありません。

2. 使用する端末機能

画面キャプチャ（MediaProjection API）

  • 目的：電子書籍の画面をOCR処理し、テキストを音声で読み上げるため。
  • 取得した画像はOCR処理後に即座に破棄します。保存・送信は行いません。
  • ユーザーが明示的に許可した場合のみ動作します。

アクセシビリティサービス

  • 目的：読み上げ中の自動ページめくりのため。視覚的な読書が困難な方の補助を目的としています。
  • 他のアプリのデータや入力内容を読み取ることはありません。
  • ページめくり操作（スワイプジェスチャー）のみを実行します。

音声合成（Text-to-Speech）

  • 端末内蔵のTTSエンジンを使用します。音声データは外部に送信しません。

3. 外部サービスへの通信

Gemini API（Google）

  • 目的：OCRで認識したテキストの誤字補正。
  • 送信内容：OCRで読み取った書籍テキストの一部（補正処理のため）。個人を特定できる情報は含まれません。
  • 読み上げ機能を使用する際に自動的に利用されます。アプリにビルド済みのAPIキーを使用します。
  • Googleのプライバシーポリシー：https://policies.google.com/privacy

パターン貢献機能（完全任意）

この機能はオプションです。「貢献する」ボタンを押した場合にのみ以下のデータが送信されます。使用しなくてもアプリは正常に動作します。
  • 送信内容：補正パターン（誤認識文字列 → 正しい文字列 のペア）、アプリバージョン、送信日時。
  • 書籍の内容・文脈は一切送信しません。
  • 送信先：開発者が管理するGoogleスプレッドシート。

4. データの保持と削除

  • 端末内のデータはアプリのアンインストールにより削除されます。
  • 任意送信した補正パターンデータの削除を希望される場合は、下記お問い合わせ先までご連絡ください。

5. 第三者への提供

収集した情報を第三者に販売・提供することはありません。

6. 対象年齢

本アプリは13歳以上を対象としています。13歳未満の方のご利用はご遠慮ください。

7. 本ポリシーの変更

プライバシーポリシーを変更する場合は、本ページおよびアプリのアップデート情報でお知らせします。

8. お問い合わせ

GitHub Issues： https://github.com/smartnavipro-dev/otovia/issues

Otovia Privacy Policy (English)

Last updated: February 24, 2026

Otovia does not collect any personal information (name, email address, location, etc.). No account registration is required.

1. Information We Collect

Otovia stores the following data locally on your device only:

  • OCR correction patterns: Pairs of "misrecognized text" → "corrected text". No book content or context is stored.
  • App settings: Reading speed, auto page-turn preferences, etc.

None of this data is automatically transmitted externally.

2. Device Permissions Used

  • Screen Capture (MediaProjection): Used only to OCR e-book text for text-to-speech. Captured images are discarded immediately after OCR processing. Never stored or transmitted. Requires explicit user permission.
  • Accessibility Service: Used only for automatic page turning during text-to-speech playback. Designed to assist users with reading difficulties. Does not read data from other apps. Only performs swipe gestures for page navigation.
  • Text-to-Speech: Uses the device's built-in TTS engine. No audio data is transmitted externally.

3. Third-Party Services

  • Gemini API (Google): Used automatically during text-to-speech playback for OCR text correction. Sends a portion of the recognized text (no personally identifiable information). Uses a built-in API key. See Google's Privacy Policy.
  • Pattern Contribution (Optional): Only when the user explicitly taps "Contribute," correction pattern pairs (no book content) and app version are sent to the developer's Google Spreadsheet.

4. Data Retention and Deletion

Local data is deleted when the app is uninstalled. To request deletion of contributed pattern data, please contact us via GitHub Issues.

5. Children's Privacy

This app is intended for users aged 13 and older.

6. Changes to This Policy

We will notify users of any changes via this page and app update notes.
